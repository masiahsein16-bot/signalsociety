How to Record as MP4

  1. Open this file in Chrome
  2. Use OBS Studio or ScreenFlow to record
  3. Set background to green screen
  4. Record each animation (pause between)
  5. In video editor, apply chroma key to remove green
  6. Export as MP4 with alpha channel (ProRes 4444 or H.264 with transparency)

Alternative: Use webscreenrecorder or Electron screen recorder for automated capture.
